# 使用的 AI 模型

| 項目 | 內容 |
|---|---|
| 模型 | **Claude Sonnet 5.5**（Anthropic） |
| 使用介面 | claude.ai（Claude 應用程式），啟用檔案與 Shell 工具，並透過桌面應用程式存取使用者的專案資料夾 `DIP-mid` |
| 使用期間 | 2026-11-08 02:45 – 2026-11-09 16:00（Asia/Taipei） |
| 用途 | 需求分析與架構規劃、程式實作、單元測試、除錯、文件撰寫、Git 與部署疑難排解 |

## 各階段使用方式

| 階段 | 模型的角色 |
|---|---|
| 規劃（P1–P3） | 只提出目錄結構與確認問題，依指示「先不做任何動作」，未建立任何檔案 |
| 環境檢查（P4–P5） | 讀取使用者資料夾的設定檔、Git 狀態、套件版本，找出 OpenCV 版本問題 |
| 實作（P5–P8） | 直接在專案資料夾建立與修改程式、測試、文件 |
| 部署（P9–P14） | 撰寫 README，協助診斷 Git 與部署問題 |

## 其他說明

- 其他 AI 工具或模型：**無**（依使用者於 P18 確認，全程只使用上述模型）。
- 模型在其執行環境中無法執行使用者的 Windows 虛擬環境與 Streamlit，無法連線 GitHub；相關驗證由使用者在本機完成（詳見 README 的失誤總表）。
